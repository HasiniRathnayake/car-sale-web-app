# Car Sale Web App

A comprehensive Java-based web application designed for buying and selling vehicles online. This platform provides users with an intuitive interface to browse car listings, manage inventory, and facilitate transactions in the automotive marketplace.

## ✨ Features

- **Vehicle Listings**: Browse and search through available car listings with detailed specifications
- **Seller Dashboard**: Manage vehicle inventory, post new listings, and track sales
- **Advanced Search & Filtering**: Filter vehicles by price, make, model, year, and other parameters
- **User Accounts**: Create and manage user profiles for both buyers and sellers
- **Responsive Design**: Mobile-friendly interface with clean and modern UI
- **Transaction Management**: Track and manage vehicle transactions

## 🛠️ Technology Stack

- **Backend**: Java
- **Build Tool**: Maven
- **Frontend**: CSS, HTML
- **Language Distribution**: 98.2% Java, 1.8% CSS
